# Для самой любимой

Статический одностраничный сайт-подарок. Без сборки — чистые HTML/CSS/JS.

## Локальный просмотр

Открой `index.html` в браузере, либо запусти любой статический сервер:

```bash
npx serve .
```

## Деплой (любой вариант, файлы не требуют сборки)

**Netlify (проще всего):** зайти на app.netlify.com/drop и перетащить папку `site`.

**Cloudflare Pages / Vercel:** создать проект, framework preset — "None"/"Other", корень — папка `site`, build command не нужен.

**GitHub Pages:**
```bash
git push -u origin main
```
Затем в настройках репозитория включить Pages → Deploy from branch → `main` / `/ (root)`.

## Важно перед тем, как делиться ссылкой

- Сайт помечен `robots: noindex` и содержит `robots.txt` — он не должен попасть в поисковую выдачу, но всё равно доступен по прямой ссылке всем, у кого она есть.
- Личные фото лежат в `photos/` в открытом виде — это не приватный доступ, а «ссылку не найти в поиске».
- EXIF/GPS-метаданные из фото уже удалены при подготовке.
